# Bugs found in play (Phase 9)

Ember's playthrough (Phase 9.5, `docs/phase9-plan.md`). One entry per bug, newest first. When
something looks wrong, press **F12** in the game: a bug snapshot goes to
`~/Library/Application Support/dw1-silicon/reports/<time>/` (the screen, the game's state, the
last minute of input, the settings, copies of the save slots and the log). Say which snapshot,
and roughly what happened; the snapshot folders stay on the Mac (they hold game data and are
never committed).

For each bug:

- **What happened** and what should have happened (on the PS1 / DuckStation, if known).
- **Where:** place, day, what you were doing.
- **Snapshot:** `reports/<time>`; the save slot just before it, if there is one.
- **Status:** open / reproduced / fixed in `<commit>` / the original game does it too.

### Toy Town battle-end camera-flag query (2026-11-14, Draft candidate)

- **Observed:** map 149 battle teardown, retiring entity slot 3/type 76 at
  (2808,0,-5242), index 0x2826; shadow query hits the native collision-span guard.
- **Diagnosis:** this is byte 2 of adjacent `STDVS_CAMERA.coord.flg` in the US PS1
  layout, not a larger collision array. Native pointer widening changes the offset.
- **Correction:** read-only typed view of the four-byte flag, unchanged raw bounds and
  all other unknown guards; no state/position/save changes. Independent of the separate
  offscreen-shadow contribution. Details and validation: `collision-camera.md`.
- **Acceptance:** on 2026-11-14 the player reports completing the whole Toy Town area
  using a combined local candidate; keyboard only, no physical controller tested. Not a
  captured complete replay or all-routes proof. The separate Great Canyon report remains
  unresolved. Original-PS1 and independent model review remain Draft gates.
- **Drafts:** https://github.com/loafykitten/dw1-silicon/pull/9 and
