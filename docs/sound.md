# Live sound volume

Generated by Codex (GPT-6.1 sol).

## Use

Choose **Sound → Volume…** in the macOS menu bar. Drag the slider from 0 to 100%,
or click the small speaker to mute/restore the last audible level. Escape or the red
close button dismisses the panel. Reopening brings the existing panel forward rather
than opening duplicates. The compact dark UI and speaker icons are original inline
HTML/CSS/SVG; there are no external resources or output-routing/AirPlay controls.

**The game keeps running while this modeless panel is open**, so its own music remains
available as feedback. Pause first if you do not want care time to advance. Game input
is withheld while the panel has focus; held input is cleared on open/close. Input newer
than a close callback is retained even if SDL delivers it in the same poll.

## Boundaries

- Only the existing SDL output-stream gain changes, in the range 0–1. macOS system/device
  volume, game C, SPU registers, sample generation, music/XA/movie decoding and headless
  WAV recording are unchanged. Without a preference file, output remains at 100%.
- SDL applies gain when consuming the stream, including PCM already queued. An asset-free
  test checks this using a real unbound SDL conversion stream, without a playback device.
- `sound.json` is stored beside, not inside, saves and picture settings. It contains
  version 1, the last audible integer `volume` (1–100) and a separate `muted` Boolean.
  Sliding to zero mutes without losing the last audible level.
- Gain changes on every slider input; preferences commit on release/keyboard change/close.
  A temporary-file/rename write preserves the previous file on failure. An error is shown
  without undoing the live gain. Malformed files remain untouched on load; defaults and
  an explanatory message are used instead. `DW1_SOUND_FILE` isolates testing preferences.
- `sound.rs` handles validation, state, typed bridge actions and persistence.
  `sound/macos.rs` owns the retained AppKit target/window and nonpersistent WebKit view.
  Closing breaks the WebKit/handler retention cycle. Owning `Rc` references keep the audio
  stream alive; window construction failure clears the SPU sink before releasing it.
- The inline page denies external resources/network, navigation bases and forms through
  its CSP. Dropped content and scripted new windows are blocked. Rust accepts bounded
  integral percentages from the main frame, not arbitrary script commands.
- `DW1_MUTE=1` still disables device creation. Without an audio output the panel explains
  that settings are kept for a later run. Headless/replay hosts never load sound preferences.
- The feature is independent of keyboard remapping, gameplay fixes and decomp changes.
  The existing submodule URL and revision remain unchanged.

## Silent preview

`--sound-preview` opens no disc, game state or saves and is **silent by default**.
No oscillator or music asset is embedded. An explicitly selected `DW1_PREVIEW_WAV`
can loop a local 44.1 kHz stereo 16-bit PCM WAV (at most 30 seconds / 6 MB); invalid
input leaves the preview silent. Do not start an audible test without the player's request.

Use isolated preferences for a manual check:

```sh
preview_home="$(mktemp -d)"
HOME="$preview_home" DW1_SAVE_DIR= \
  DW1_SOUND_FILE="$preview_home/sound.json" \
  target/release/dw1 --sound-preview
```

- Clean standalone workspace: **240 passed, 0 failed, 27 fixture-dependent ignored**.
  Release arm64 build passes. Native before/after new-game: **19/19 canonical checkpoints
  identical**, and the 47,171,368-byte headless WAV is byte-identical. These are native
  regression checks, not a new full-playthrough or original-PS1 certification.

  at the stored level. This is **not** claimed as interactive verification of this exact
  independently rebased contribution.

  interaction still require acceptance. No new audible or GUI tests are run for publication.
- **Only keyboard/mouse interaction was attempted. No physical controller was available
  or tested.** Gamepad mappings are not changed. VoiceOver, fullscreen/multiple displays,
  and device disconnect/recovery remain unverified.
- The repository's independent model-review gate is outstanding; no completed Sol/Astra
