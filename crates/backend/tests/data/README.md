# gte_ref.bin

Reference outputs of the PS1 GTE, produced by PCSX-Redux from generated (synthetic) inputs.
No game data is involved.

- Origin: DW2-PC (github.com/Wyrelade/DW2-PC, CC0), `tests/gte_ref.bin`, commit 2d491b5,
  generated by its `tools/gte_probe.py`.
- Format: 13 commands x 96 cases, 33 little-endian u32 words per case: data registers 0..31
  (as `mfc2` reads them), then FLAG (`cfc2 $31`). The inputs are not in the file; the test
  regenerates them with the same xorshift generator as DW2-PC's `tests/gte_test.c`.
