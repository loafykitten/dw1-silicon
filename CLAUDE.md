# dw1-silicon

A native arm64 macOS port of Digimon World (PS1, USA SLUS-01032), built from the
jype0/dw_decomp matching decompilation with the PS1 libraries replaced by a Mac layer
written in Rust (DW2-PC is the reference). **Read `PLAN.md` before doing anything**:
it's the handoff, with the goal, ground rules, sources, architecture, oracle, phases
and open questions.

- **Birdra destination text proposal (2026-11-10):** the native US textbox routine uses an
  uninitialised advance on leading spaces. A seven-line native-only decomp correction gives
  it a neutral initial advance (or one fixed cell), retaining assigned numeric padding.
  The player confirmed the blank-name fix on the combined local build; this contribution
  is independently based on phase0 and contains no other local fixes. The real-C synthetic
  regression covers 60 combinations; clean workspace 228/0/27, debug/release checks pass.
  See `docs/bugs.md`. Original PS1 spacing/pixels and independent model review are NOT
  claimed; keep this a draft. Dependency wiring must be restored to upstream before merge.
  Companion implementation: https://github.com/loafykitten/dw_decomp/pull/2 (base `dw1-native`).
  Generated by Codex (GPT-6.1 sol).
