# dw1-silicon

A native arm64 macOS port of Digimon World (PS1, USA SLUS-01032), built from the
jype0/dw_decomp matching decompilation with the PS1 libraries replaced by a Mac layer
written in Rust (DW2-PC is the reference). **Read `PLAN.md` before doing anything**:
it's the handoff, with the goal, ground rules, sources, architecture, oracle, phases
and open questions.

- **Toy Town camera-flag query (2026-11-14, isolated Draft contribution):** live map-149
  battle-retirement capture identifies index 0x2826 as STDVS_CAMERA.coord.flg byte 2.
  Model only its four read-only PS1 bytes through generated native fields; raw collision
  bounds and all other unknown neighbors stay guarded. Companion changes only native
  getTileTrigger reads; drop_shadow.c and other proposals are not included. Workspace
  230/0/27, release and 28x3 sanitized real-C scenarios pass. Player reports completing
  all Toy Town on a combined local app; not a captured full replay or all-routes proof.
  Keyboard only, no controller tested. Great Canyon and original-PS1/independent review
  gates remain open. Published independent Drafts: https://github.com/loafykitten/dw1-silicon/pull/9
  and https://github.com/loafykitten/dw_decomp/pull/4. Fresh public checkout fetches both
  pins via the unchanged upstream URL and passes sanitizer, workspace 230/0/27 and release.
  Native reconstructed shadow guard-before/pass-after and 19/19 new-game state / identical
  WAV also pass on the clean contribution. See `docs/collision-camera.md`. No installed
  app/player data changes during preparation. Generated by Codex (GPT-6.1 sol).
